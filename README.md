Python Practice – 30 Programming Exercises

A collection of 30 Python programming exercises designed to practice problem-solving and improve programming skills. The exercises are organized into three difficulty levels: Beginner, Intermediate, and Advanced.

📌 Project Overview

This project contains 30 exercises covering fundamental Python concepts, algorithms, data structures, object-oriented programming, file handling, and problem-solving techniques.

🟢 Beginner Level (Exercises 1–10)

#| Exercise| Description
1| Prime Number Checker| Checks whether a number is prime.
2| Factorial Calculator| Calculates the factorial of a non-negative integer.
3| Largest Digit| Finds the largest digit in a given number.
4| Reverse a Number| Reverses the digits of an integer.
5| Number Palindrome| Checks whether a number reads the same forward and backward.
6| GCD and LCM| Calculates the Greatest Common Divisor and Least Common Multiple of two numbers.
7| Star Pyramid| Prints a centered pyramid pattern using stars.
8| Vowels and Consonants Counter| Counts vowels and consonants in a string.
9| Remove Duplicates| Removes duplicate elements from a list while preserving their order.
10| Second Largest Number| Finds the second-largest distinct number in a list.

🟡 Intermediate Level (Exercises 11–20)

#| Exercise| Description
11| Bubble Sort| Sorts a list using the Bubble Sort algorithm.
12| Common List Elements| Finds elements shared by two lists without duplicates.
13| Anagram Checker| Checks whether two strings are anagrams, ignoring spaces and letter case.
14| Word Frequency Counter| Counts how many times each word appears in a sentence.
15| Calculator| Performs addition, subtraction, multiplication, and division using separate functions.
16| Student Grade Manager| Stores student grades and calculates the average and highest grade.
17| Most Frequent Element| Finds the most frequently occurring item in a list.
18| Decimal to Binary| Converts a decimal integer to binary without using the built-in "bin()" function.
19| Password Validator| Checks password strength based on length and character requirements.
20| Contact Manager| Adds, searches, and removes contacts using a dictionary.

🔴 Advanced Level (Exercises 21–30)

#| Exercise| Description
21| Binary Search| Searches for an element in a sorted list using Binary Search.
22| Merge Sorted Lists| Combines two sorted lists into one sorted list without using "sort()".
23| N-Queens Problem| Solves the N-Queens puzzle using backtracking.
24| BFS Shortest Paths| Uses Breadth-First Search (BFS) to find shortest distances in an unweighted graph.
25| Library Management System| Manages books, available copies, borrowing, and returning using classes.
26| Bank Account System| Demonstrates inheritance using bank account and savings account classes.
27| User Authentication| Implements basic user registration and login with JSON file storage.
28| To-Do List| Creates and manages tasks with persistent JSON file storage.
29| Inventory Management| Manages product quantities, sales, prices, and total inventory value.
30| Word Guessing Game| A terminal-based word guessing game with limited attempts.

- JSON File Handling
- Exception Handling
- Regular Expressions

🎯 Project Goal

The goal of this project is to strengthen Python programming skills through practical exercises, gradually progressing from basic programming concepts to more advanced algorithms and software design.
